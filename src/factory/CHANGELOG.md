# 智能字幕工厂版本记录

## 4.1.9（2026-10-15）

- 统一生成页与校对验证页的字体、控件高度、圆角、边框、间距和状态色。
- 任务区保留视频与文件夹导入、日志、清空和全局拖拽；校对区保留重复标红与只看标红。
- 修复文件夹拖拽的入口数量限制，支持与“导入文件夹”一致的批量递归导入。
- 修复仅翻译批量任务中单个任务缺少原声字幕时阻断整批任务的问题：该任务单独失败，后续任务继续执行，并在执行前预估中提示。
- 修复识别和翻译同时关闭时仍进入无实际动作执行的问题，并让仅识别按钮准确显示当前本机或云端识别方式。
- 校对任务下拉框在同名视频来自不同目录时显示父目录，避免选错任务。
- 识别、翻译、缓存和模型运行逻辑仍沿用 4.1.8 的兼容规则与断点标识。

## 4.1.8（2026-10-15）

- 本机识别增加长英文/乱码模板检测，并保留短拟声与正常低声对白的既有规则；旧缓存不绕过本版规则。
- 本机翻译增加受控语义脱离检查，长异常源文在模型调用前进入明确省略终态；省略只影响译文，原声和队列继续保留。
- 云端翻译增加单条连续重复收束，并补齐成功、重试成功、缓存命中、最终省略和批次终态诊断，校验输入与输出数量一致。
- 版本、识别指纹、翻译缓存和四份规则说明统一升级到 4.1.8。

## 4.1.7（2026-10-14）

- 本机识别以多项声学证据、时间定位和残片完整性联合过滤，保护相邻否定语义的完整断句。
- 本机翻译按原声拦截无关说明，完善已有术语及有重复证据的任务内中文称呼，减少短句误判。
- 云端翻译校验拒答、解释、目标语言及缓存内容；内容重试耗尽仅省略对应译文，保留其他成功条目。
- 两种翻译分别清理时间相近、连续三条以上相同译文，只留第一条且不延长时间。
- 可信缺译和空译文完成记录适配云端，原声保持只读，校对仍可补齐缺译。
- 修复阿里云明确失败后的重建、导入退出等待保存、编号字幕手动导入后的成品命名。
- 更新四份独立规则说明；保留四路隔离、启动首帧保护、托盘运行和资源释放逻辑。

基于 4.1.6 修复批次 3；旧发布目录保留。

# 智能字幕工厂 4.1.9

## 4.1.9 当前行为

- 新增收紧本机识别、本机翻译、云端翻译规则；云端识别不套用本机强过滤。四份 TXT 为当前完整规则，下方旧版本说明仅供追溯。
- 内容不合格有限重试后仅省略对应译文，保留原声和其他译文，继续本视频；服务或无法可靠对齐的结构故障使当前项失败并保留断点，后续视频继续。
- 两种翻译连续三条以上完全相同且相邻各不超过 1.5 秒，只留第一条，不延长时间；自然两次重复保留。
- 原声只读；可信缺译、空译文可恢复完成状态，校对可补齐空行。字幕格式合格不等于语义必然准确。
- 阿里云确认失败后下一次开始可重建该失败项，可能产生新费用；运行中或提交结果未知的任务不盲目重交。
- 退出等待导入收尾及保存；手动导入编号版字幕后输出恢复媒体原名。
- 识别和翻译仍默认本机；无需安装 Python 或独立模型服务，完整目录内附双模型和运行环境。
- 只替换程序目录，不改动用户字幕。成功任务缓存自动清理，任务诊断用于分析；旧版仍可保留。

以下为历史说明，与本节冲突时以 4.1.8 和当前四份规则 TXT 为准。

## 4.1.6 当前行为

- 默认本机 Whisper Small 识别和 Hy-MT2 翻译，也可以分别切换阿里云识别和云端翻译，四种组合均可使用。只要原声有效，关闭识别即可仅翻译；关闭翻译则仅生成原声。
- 本机识别减少弱片段和异常循环；同类气声间隔不超过 0.8 秒时合并。正常短回应与两次口语重复继续保留。
- 本机翻译独立重试后仍无法生成合格中文时，仅省略该条译文。原声文本、编号和时间轴保持完整；译文重新编号但时间位置不变。原文、失败结果和时间在翻译诊断中保留。绝不写入“待复核”等占位词，也不写空白 SRT 块。
- 全片没有有效对白时，允许生成零条原声并写入完成记录；全部译文被丢弃时，仅译文为空，原声完整保留。空译文必须有匹配的完成记录，不代表翻译质量已由人工验收。
- 校对按原声时间轴匹配译文，缺译显示空白编辑项，可手动补填；导出跳过空译文。全部留空时提示没有可输出译文，不创建无内容成品。
- 强制执行隔离旧识别断点与翻译缓存；关闭识别时，强制执行仅重做翻译。缓存绑定当前任务、原声与上下文、模式和规则版本，成功后清理。
- 识别先写临时文件再提交正式原声，异常空文件不会阻塞重新执行。关闭软件会取消尚未启动的任务；勾选关闭至托盘时继续运行。
- 云端音频提取独立超时为 600 秒，超时后回收进程与临时音频。单个任务失败后继续后续视频；队列暂停会显示原因和未执行数量，不再误报全部完成。
- 四套自然语言规则在同目录的四份 TXT 中；`字幕工厂收束规则说明.txt` 为索引。下列历史版本记录仅供追溯，与本节冲突时以 4.1.6 当前行为为准。

## 4.1.5 本版操作补充

- 识别设置新增“启用识别”。关闭后，任务必须已有可读取的原声字幕，开始执行会进入仅翻译模式；强制执行在该模式下只重新翻译，不会重新识别。
- 开始执行前会显示任务数量、预计耗时、预计空间和当前可用空间。空间不足或无法读取空间信息时不会启动任务。耗时基准为本机识别 40 分钟、本机翻译 35 分钟、云端识别 6 分钟、云端翻译 4 分钟（均按 2 小时视频线性估算）。
- 本机处理模式增加“均衡 CPU”，用于降低本地模型的线程占用；实际耗时和占用取决于电脑硬件，不保证固定百分比。
- 勾选“关闭后缩小至托盘”后，点击右上角关闭会直接进入托盘，任务继续运行；未勾选时点击关闭会直接退出软件，不再弹出选择框。托盘右键只提供显示主窗口和退出软件。队列结束后发送一次 Windows 完成通知。
- 队列状态在主窗口显示“本轮完成 X 项，失败 Y 项，耗时 Z”；单项失败会保留诊断和断点并继续后续任务。

## 字幕生成

1. 拖入或选择视频，使用上下箭头排序。导入时检查视频/音频，失败文件不加入任务。
2. 本机识别固定使用内置 Whisper Small，不加载副模型，也不再提供 Base、场景预设、热词或识别辅助选项。需要付费高速识别时可切换阿里云接口。
3. 默认识别与翻译均启用并使用内置本机模型，无需 API Key。只要原声时关闭翻译；使用云端翻译时填写 API Key、模型名称、Base URL 等参数。默认接口为 DeepSeek，支持 OpenAI 兼容聊天接口。
4. 选择生成目录，留空则使用各视频所在目录。保存设置，下次自动恢复；导出设置不包含 Key，导入保留当前 Key。Key 在本机加密保存。
5. 点击开始本地识别，按顺序输出本地结果；勾选启用翻译时，点击开始执行会继续生成译文。输出 视频名.原声.srt、视频名.译文.srt；诊断、复核和断点放入“视频名-产物”文件夹。同名自动编号，不覆盖。译文可直接手动加载到播放器，无需进入校对页。

自动重试次数默认 2（首次请求失败后最多再试 2 次，共 3 次），可设 0～10，0 表示不重试；每个翻译批次分别计数。网络异常、超时、服务繁忙和不完整译文自动重试；Key/参数无效等不可重试错误及 max_tokens 截断直接提示修正，手动取消立即停止。该设置支持保存、恢复和导入导出；旧设置自动补为 2。

失败任务会显示原因并继续后续任务；取消停止队列，已生成文件保留。识别与翻译中断后，点击开始可以恢复当前任务仍然有效的断点。已有有效原声时直接翻译，已有配对译文时视为完成。需要重新请求时使用强制执行；仅翻译时先关闭识别。

任务列表重启可恢复，但不自动运行。查看任务日志可定位错误；清除翻译缓存不会删除已生成 SRT。一次批量任务共用主模型，关闭或取消时停止后台识别进程。

## 校对验证

主动加载已生成任务，或点击导入原声 + 译文，依次选择两份 UTF-8 SRT。条数、编号、时间轴必须对应，不会静默错配。非 UTF-8 字幕先转换编码。

可编辑译文、查找下一个、替换当前、全部替换。日文假名、英文和自定义词命中标红；自定义词用逗号分隔。纯汉字无法仅凭字符判断是不是日文，标红仅是提醒。目标语言为日语/英语时暂时停用相应残留检测，切换回其他语言会恢复用户的勾选偏好。

选择独立成品目录，点击验证并导出。检查结构、时间轴、重叠、空译文、条目完整性，保存后重新读取验证；成品名为 原名.srt，自动防覆盖。格式通过不代表台词/翻译准确。未导出修改在关闭或重新加载时提醒。

## 测试建议

先用 1～2 分钟的视频测试本地识别，再跑长视频。启用翻译前确认 Key/模型/地址有效。第一轮不勾检查主流程；第二轮再勾。查看生成字幕，按需校对。纯静音不会调用翻译；无语音时会明确提示并保留空原声结果。

不做云端语音识别，不烧录或封装。字幕翻译会向配置的服务发送文本，视频和音频不上传。服务的 JSON 输出兼容性、额度和模型可用性以实际接口为准。


## 4.0.9 本地 Hy-MT2 翻译与字幕收束

- 翻译设置可在“本地模型”与“云端接口”之间切换。选择本机模型时，API 参数继续显示但全部锁定，API Key 位置显示内置 Hy-MT2 模型；切换云端后恢复 API Key 编辑。默认使用本地模式；勾选“启用翻译”后，本地模式自动使用发布包 `models` 目录中的 `Hy-MT2-1.8B-Q4_K_M.gguf`，软件会自动管理本地服务，不需要用户手动启动。云端模式继续使用 API Key、模型名称和 Base URL。
- 本地模式逐条翻译并校验纯中文输出；失败按“自动重试次数”重试，默认 2 次。接口拒绝、空译文、日文/英文残留或格式不合格会提示失败，不会把不合格文本写进成品。
- Hy-MT2 本地模式的目标语言固定为中文，模型随发布包自动选取。服务未启动时软件自动启动，不会先跑完整识别再失败。
- 识别完成后，正式原声字幕会按规则清理：连续 3 条或以上相同内容只保留第一条，后续条目删除。原始识别证据仍保留在诊断文件中，任务记录会保存清理数量。
- 翻译完成后，按原声重复关系同步收束译文；连续完全相同的译文也会收束，保证原声和译文条数、时间轴继续对应。规则不会改写诊断文件。
- 切换本地/云端只影响翻译阶段；已有同一识别版本的原声可以直接进入新的翻译后端，不会因翻译设置变化而重新识别。缓存指纹包含后端、模型和规则版本，切换后不会误用另一后端的缓存。
- 本版正式发布包目录为 `release/4.0.9/智能字幕工厂-win32-x64`。本地翻译会优先复用已经运行的 8092 服务；没有外部服务时，软件会自动查找并启动 `llama-server.exe`，任务完成、取消或退出时只关闭软件自己启动的服务。运行时可放在发布包 `resources\\runtime` 或 Hy-MT2 模型同目录。
- 识别阶段不会加载 Hy-MT2；只有进入翻译阶段后才启动或复用服务。批量任务的多个视频共用一次加载，翻译结束后释放。
## 3.0.2 更新

请求超时按秒填写，默认 120 秒。旧版默认 30000 毫秒自动升级为 120 秒；其他自定义值换算为秒保留。新版再次保存的自定义 30 秒不会重复迁移。旧设置文件仍可导入。

退出软件后打开同一识别引擎版本，原有失败任务会恢复。保持视频、识别参数、生成目录及原声字幕不变，点击开始执行即可复用原声进入 API 翻译；更改请求超时或重试次数不触发重新识别。跨识别引擎版本升级时，未完成任务会按新版重新识别，旧版中途结果没有新版窗口断点。

## 3.0.3 稳定性修订

校对导入/导出时锁定编辑与替换，导出成功才清除对应的修改标记；失败保留修改。关闭窗口会先保存最新指定词、检测偏好和成品目录；有未导出字幕或执行任务仍会提醒，校对内容没有自动草稿。刚点击开始后立刻取消或退出，也会停止尚在准备的任务。

导出保留原始合法字幕编号，外部非连续编号也可再次与原声配对。请求超时支持 1～3600 秒、最多三位小数。接口拒绝、格式错误、HTTP 错误和超时分别提示，明确拒绝不会重复请求，普通格式错误仍按重试设置处理。

## 3.0.4 本机识别流程优化

继续使用 Whisper Small/Base，不新增主模型。默认热词和上下文为空，后台不再自动追加指令；旧保存内容原样保留。建议测试时展开“识别辅助”，点击“清空提示”，保存后使用同一段视频比较；需要人名或专用词时少量填写。

放宽语音检测并保留句首句尾上下文，完整语音段识别后按真实词时间拆分，每条不超过 5 秒。可疑片段最多额外识别一次；疑似遗漏范围用更低阈值的语音检测补查，纯音量不是补字幕依据。补识别受整片次数、音频总时长与耗时预算限制，已开始的一次识别允许完成。证据不足不会因文字更多而自动替换原结果。

每次识别额外保存“视频名.识别诊断.jsonl”，含送入模型的音频范围、原始文字与词时间、清洗/不采用原因、补识别结果及待复核位置。任务显示待复核数，点击“诊断”可在文件夹中定位文件，用文本编辑器查看。无法可靠定位的内容保留在诊断中，不伪造时间或强行塞入成品字幕；诊断可能包含台词原文，不额外保存整片音频。

任务旁“重识”将任务排入重新识别，后续是否翻译取决于开关；点击开始执行后运行，旧字幕防覆盖。旧引擎结果不会被当作新版识别结果复用；旧失败任务再次执行会重新识别。已完成任务不会自动重跑，需主动点“重识”。新版识别完成后仅翻译失败，则再次执行可复用新版原声。

识别质量以实际音频人工核对为准，不把字幕数量增加、模型分数或格式验证通过当成准确率证明。

## 3.0.5 仅本地识别

以后勾选启用翻译、填好接口设置并开始执行，会接着本地识别完成的任务生成译文；识别设置、路径和文件未变化时复用本版原声。仅原声任务不出现在校对页的已生成译文列表中。纯静音本地任务保留空原声与诊断并明确提示。

## 3.0.6 完整本地识别

现有 Small/Base 模型不变。连续窗口覆盖全片音频，语音检测辅助分段，不再直接丢弃未命中区域。疑难复听按十分钟时间段分配预算，正常识别不受旧版 24 次上限限制。完整覆盖预计更耗时，进度显示正在处理的窗口。

任务新增“复核”，打开对应的“视频名.待复核.txt”，列出可疑时间点、文字、原因及处理结果。诊断继续保留原始识别和实际输入范围。复核提醒不等于字幕错误，也不表示已人工听音确认。

旧完成任务需要主动点击“重识”才能比较新流程，原文件自动编号保留。新版生成的原声仍能在之后启用翻译时复用。已保存的热词和上下文继续保留；需要测试空提示时先清空并保存。

## 3.0.7 续跑与识别整理

- 新任务每处理完一个识别窗口，会在生成目录的「.字幕工厂断点」文件夹保存记录。取消或关闭软件后，保留原任务、原片、模型、识别设置和输出目录，再次开始执行可恢复已完成的窗口；正在处理但未保存的窗口会重跑。
- 「重识」明确从头重新识别；普通中断后直接「开始」继续。恢复仍需加载模型、读取音频和检查记录，不会瞬间完成。对照中断后会重做对照，翻译继续使用原有独立缓存。
- 断点不覆盖旧字幕，新一次输出仍自动编号；删除断点只会使以后无法从该处恢复。旧版没有断点的失败任务无法凭空恢复到中途。
- 复听前检查整句边界、避免同范围重复复听；纯数字静音不入模，低音量内容仍正常处理。
- 在较低音量的停顿附近选择分段点，增加上下文；谨慎合并紧邻短碎片，疑似气声且证据不足的结果保留在待复核清单。
- 本版保留原本首遍识别参数。更快参数已做短样本实验，但出现文字退化，未设为默认。整片速度和质量请结合实际影片测试。

## 3.0.9 对白优先与全流程整理

- 默认勾选“仅保留对白”：过滤独立气声、连续呻吟和笑声描述；保留“はい”“うん”“ううん”等短回应和带实际对白的整句。按文字形态判断存在边界，必要时取消勾选后重识对照。过滤内容留在诊断及待复核清单，不凭空修改原音。
- “启用热词与提示”默认关闭。升级或导入旧设置后，原填写内容保留，界面会提示当前不参与识别；明确勾选才使用。建议热词仅填少量人名、专有名词。

## 4.1.3 使用补充

### 收束规则

识别和翻译收束规则已整理在同目录的 `字幕工厂收束规则说明.txt`。识别诊断和翻译诊断只用于分析；识别断点只用于恢复识别窗口；翻译缓存只用于恢复或复用翻译条目。

### 翻译缓存位置

Windows 默认位于 `%APPDATA%\智能字幕工厂\translation-cache`。正常完成的任务会清理本次使用的缓存，失败、取消或中断任务会保留缓存，下一次执行时可以继续。删除译文字幕后，软件会根据原声字幕进入仅翻译流程；如果缓存仍在，会优先复用缓存，否则重新翻译。需要重新请求时，点击“清除翻译缓存”。

## 4.1.3 规则收束补充

- 识别完成后会删除“笑声、呻吟声、吐息、呼吸音、音乐”等纯声音描述，并把重复字幕、同条内部三次以上重复收束后重新编号；处理记录写入识别诊断 JSONL。

- 修复本机翻译中正常中文标点被误判的问题。中文问号、叹号、括号、冒号等不会再因此造成台词丢弃；日文、英文、乱码和内部占位词仍按本机规则拦截。
- 原声和译文完成记录绑定具体视频，统一输出目录下不同路径的同名视频不会互相认领字幕。继续翻译已有原声时不重复执行识别过滤，云端识别来源会随任务恢复。
- “开始执行”始终可以重新检查有任务的列表。外部删除或移走译文后，无需重启，点击开始会按现有原声补做翻译；产物齐全则提示任务已完成。
- 校对修改会保存到 `%APPDATA%\智能字幕工厂\editor-draft.json`，关闭前提交尚未保存的修改，下次启动自动恢复；成功导出或明确加载其他字幕后清除旧草稿。草稿允许暂时空白的编辑内容，但正式导出仍检查空字幕和时间轴。
- 未勾选缩小至托盘时直接退出，不新增关闭选择弹窗；退出会等待正在进行的导出。勾选托盘时仍隐藏窗口并继续任务。
- 四套规则保持独立：本机识别、云端识别、本机翻译、云端翻译。云端翻译不套本机的固定词表和纯中文删句规则。
- 原修复前已经丢弃的台词不会自动补回；要恢复这部分内容，需对相应视频强制执行重新生成。

### 当前修复补充（版本仍为 4.1.6）

- 本机翻译断连、超时或接口异常在恢复及重试耗尽后，本视频显示失败，完整原声和有效翻译缓存保留，后续视频继续执行。再次开始可恢复翻译；服务故障不会再导致原声被清空并误报完成。内容质量失败只收束或省略译文，不再同步删除原声。
- 启动小窗口先完成自身首帧、图标和字体加载再显示，阶段更新按顺序送达；主界面真正就绪并绘制后才切换。加载较慢时继续显示等待信息，不因 8 秒超时冒充完成。主窗口准备好后淡入，小窗口进度条完成后淡出。
- 翻译提示词框记忆最后一次可见时的有效高度。切回本机、切换页签或关闭软件不会再用隐藏状态的零高度覆盖尺寸；旧修复前已经丢失的尺寸需要重新调整一次。

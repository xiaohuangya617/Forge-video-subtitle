# 智能字幕工厂 4.1.92

Windows x64 免安装字幕生成与翻译工具。程序可以从本地视频提取音频，生成原声字幕，再按需生成中文译文，并提供字幕校对、验证和导出。

**[下载 Windows 完整版 ZIP（约 1.81 GiB）](https://github.com/xiaohuangya617/Forge-video-subtitle/releases/download/v4.1.92/smart-subtitle-factory-v4.1.92-windows-x64.zip)**

## 小白用户：下载即用

这是一个完整运行目录，不是单文件程序。

1. 下载发布包并完整解压到有写入权限的磁盘目录。
2. 保留解压后的整个 `智能字幕工厂-win32-x64` 文件夹。
3. 双击 `智能字幕工厂.exe` 启动。

不需要另外安装 Python、FFmpeg 或模型。请不要只复制 EXE；删除 `resources`、`models` 或其他 DLL 会导致程序无法启动或功能不完整。首次使用建议先用 1～2 分钟的视频测试。

## 具体使用步骤

### 1. 首次启动与保存设置

1. 双击 `智能字幕工厂.exe`，等待启动页结束后进入“字幕生成”。
2. 在“识别设置”中选择“本机模型”或“云端接口”。首次使用建议选择“本机模型”，不需要账号和 API Key。
3. 在“翻译设置”中选择“本机模型”或“云端接口”。只想生成原声字幕时，关闭“启用翻译”。
4. 需要云端翻译时，打开“云端接口”，填写 API Key、模型名称、Base URL、目标语言、超时和重试次数。默认值是 DeepSeek 兼容接口；需要使用其他服务商时，按服务商文档填写完整 Base URL。
5. 需要云端识别时，在“识别设置”切换“云端接口”，填写阿里云 DashScope API Key、模型名称和 Base URL。云端识别会上传从视频提取的音频并按服务商规则计费。
6. 点击右上角“保存设置”。API Key 不会包含在“导出设置”文件中；导入设置后仍需使用当前电脑中保存的 Key。

### 2. 生成原声字幕或译文

1. 点击“导入视频”，选择一个或多个视频；也可以点击“导入文件夹”批量递归导入。列表中的上下箭头可以调整执行顺序。
2. 在“生成输出”中选择统一输出目录；留空时，结果写入各视频所在目录。
3. 根据需要选择处理方式：
   - **本机识别 + 本机翻译**：完全离线，首次加载模型较慢，占用较多内存和 CPU。
   - **本机识别 + 云端翻译**：原声在本机生成，只把字幕文本发送给翻译服务商。
   - **云端识别 + 本机/云端翻译**：先提取音频上传到阿里云，再进入翻译阶段。
   - **仅翻译**：关闭“启用识别”，并确保任务已有匹配的原声 SRT；程序不会重新识别视频。
4. 点击“开始执行”。程序会先显示任务数量、预计耗时、预计空间和可用空间，确认后才开始处理。
5. 处理过程中可以查看进度和任务日志。单个视频失败不会自动阻断后续任务；取消会保留已生成文件和有效断点。
6. 任务完成后，在输出目录查看 `视频名.原声.srt`、`视频名.译文.srt` 和 `视频名-产物` 目录。需要重新处理已有任务时使用“强制执行”，它会重新生成对应阶段。

### 3. 中断后继续

- 软件异常退出、电脑重启或手动取消后，重新打开软件，任务列表会恢复，但不会自动开始。
- 保持视频路径、生成目录和设置不变，点击“开始执行”即可继续有效断点。
- 云端识别在提交结果未知时会保留任务状态；不要连续重复提交，重新开始时让程序先查询上一次任务状态。
- 想让任务在关闭主窗口后继续运行，可勾选右上角“关闭后缩小至托盘”；托盘菜单可以重新显示窗口或退出软件。

### 4. 校对并导出字幕

1. 切换到“校对验证”页签，在任务下拉框选择已经生成的任务并点击“加载”。也可以点击“导入原声 + 译文”，手动选择两份 UTF-8 SRT。
2. 原文列只读，译文列可以直接编辑。使用“查找下一个”“替换当前”或“全部替换”修改文本。
3. 勾选“日文残留”“英文残留”，或在指定词框中填写逗号分隔的词语；“重复标红”和“只看标红”用于缩小检查范围。
4. 选择独立的“成品输出”目录，点击“验证并导出 SRT”。程序会检查编号、时间轴、重叠和空译文，验证通过后生成不覆盖原文件的成品。

### 5. 常见问题

- **程序打不开**：确认是完整解压后的目录，检查 `resources`、`models`、`智能字幕工厂.exe` 是否仍在同一目录；不要放在没有写入权限的位置。
- **本机处理很慢**：首次加载模型会明显耗时；可在本机处理模式选择“均衡 CPU”降低占用，但会进一步增加耗时。
- **云端提示失败**：检查 API Key、模型名称、Base URL、账户额度和网络；不要把 Key 写入提示词或公开日志。
- **仅翻译没有任务**：同名视频旁边必须存在可读取的原声 SRT，或者先在“校对验证”页签导入原声与译文。
- **结果不理想**：字幕结构通过不代表语义准确。先用短视频确认音频质量、语言、模型和提示词，再处理长视频。

## 已确认功能

- 支持导入 `MP4`、`MKV`、`MOV`、`AVI`、`WEBM` 视频，可批量添加和排序。
- 本机语音识别：内置 Whisper Small 模型，离线生成原声 SRT。
- 云端语音识别：可配置阿里云 DashScope 文件转写接口。
- 本机翻译：内置 Hy-MT2 1.8B GGUF 模型，默认目标语言为中文。
- 云端翻译：支持 DeepSeek 等 OpenAI 兼容聊天补全接口。
- 支持仅识别、仅翻译、识别后翻译以及本机/云端组合模式。
- 任务队列、批量继续、取消、失败后重试、断点恢复和防覆盖输出。
- 输出原声字幕和译文字幕，保留诊断、缓存和任务状态。
- 字幕校对：导入原声与译文 SRT，编辑、查找替换、重复提示、结构验证和导出。
- 设置导入导出；导出的设置不包含 API Key，Key 在本机加密保存。
- 可选择关闭窗口后缩小到托盘并继续任务；退出时会等待必要的保存和导入收尾。

## 输出文件

常规任务会在视频所在目录或用户指定目录生成：

- `视频名.原声.srt`
- `视频名.译文.srt`
- `视频名-产物` 目录：诊断、断点、缓存和任务记录

程序不会覆盖已有同名成品，会自动编号。字幕格式通过检查不代表翻译内容已经人工验收。

## 云端服务与隐私

- 本机识别和本机翻译可以离线运行，不需要 API Key。
- 云端翻译会把字幕文本发送到用户配置的服务商，并产生服务商费用。
- 云端识别会先从视频提取音频，再上传到用户配置的阿里云服务；视频文件本身不会直接作为视频上传。
- API Key、模型名称、Base URL 和超时等设置由用户负责；请勿把包含密钥的设置或诊断文件公开分享。
- 服务商的额度、区域、模型可用性、隐私政策和计费以服务商当前规则为准。

## 已知限制与缺陷

- 当前发布包仅面向 Windows x64，没有 macOS、Linux 或移动端版本。
- 完整目录未压缩约 2.54 GiB；内含约 1.13 GiB 的本地翻译模型和约 483 MiB 的本地识别模型。运行、临时音频、缓存和输出还需要额外磁盘空间。
- 本机识别和翻译会占用较多 CPU、内存和处理时间；实际速度取决于电脑硬件，当前发布包不保证 GPU 加速。
- 云端模式依赖网络、API Key、模型权限和服务额度；请求超时或服务商故障可能需要稍后继续任务。
- 长视频、低清音频、多人同时说话、背景音乐、特殊编码或损坏媒体可能导致识别缺句、时间轴偏差或翻译质量下降。
- 当前输出以 SRT 字幕为主，不负责把字幕烧录进视频，也不重新编码视频。
- 本次目录审查通过了清单哈希、JavaScript/Python 语法和静态路径检查；没有使用真实视频完整运行识别、翻译和长队列，因此不能宣称所有媒体和模型场景均已验收。
- 目录中包含运行脚本和第三方运行库，但不包含完整的开发工程、构建脚本和依赖锁文件；本发布包应按“可运行二进制目录版”使用，不能保证从该目录复现构建。
